# RFID Chameleon

**[English version](README_en.md)**

Android-приложение для чтения и записи RFID-меток филамента через **[Chameleon Ultra](https://github.com/RfidResearchGroup/ChameleonULtra)** по Bluetooth LE. Переносит ключевые сценарии BoxRFID-Touch на телефон: QIDI, OpenSpool, Snapmaker U1, сохранённые метки и импорт/экспорт `.bin`.

Приложение работает **только по BLE** — USB-подключение не используется. Управлять самим Chameleon (слоты, эмуляция, DFU, прошивка) нельзя: он выступает как RFID-ридер/писатель.

## Возможности

- **QIDI**
  - Модели QIDI Plus 4 / Max 4 и QIDI Q2.
  - Чтение и запись MIFARE Classic 1K, блок 4, ключ A `FFFFFFFFFFFF`.
  - Встроенные списки материалов, 24 цвета, производители.
  - Импорт CFG-файла QIDI для собственного списка материалов.
- **OpenSpool**
  - Чтение и запись NTAG215/216 в формате NDEF JSON.
  - Профили **OpenSpool Standard** и **Snapmaker U1**.
  - Версии данных Basic / Standard / All (U1), пресеты материалов и выбор цвета.
  - Дополнительные поля U1: подтип, alpha, температуры стола, вес, диаметр, доп. цвета.
- **Сохранённые метки**
  - Сохранение только по явной кнопке **«Сохранить в данные»**.
  - Автоматическое имя, переименование и удаление.
  - Повторная запись метки из сохранённой записи.
  - Экспорт `.bin` и импорт `.bin` с автоопределением типа по размеру.
- **Snapmaker U1**
  - Настройка host/port и проверка связи по HTTP.
  - Просмотр состояния ToolHead.
  - Отправка данных OpenSpool U1 на принтер — **без Chameleon**, телефон и принтер должны быть в одной Wi-Fi сети.
- **Интерфейс**
  - Русский и английский языки.
  - Автопоиск Chameleon и автоподключение к последнему устройству.
  - Последняя вкладка и выбранные параметры меток запоминаются.

## Что нужно

- Android-смартфон с Bluetooth LE.
- Chameleon Ultra, подключённый по BLE. В коде есть распознавание Lite, но основной проверенный сценарий — Ultra.
- Метки:
  - **MIFARE Classic 1K** — для QIDI;
  - **NTAG215 или NTAG216** — для OpenSpool и Snapmaker U1; NTAG213 не поддерживается.
- Для отправки на U1: принтер Snapmaker U1 в той же сети, HTTP-порт по умолчанию `7125`.
- Разрешения Android: Bluetooth / «Устройства поблизости»; на старых версиях Android также геолокация.

## Как пользоваться

1. Откройте вкладку **«Подключение»** и дождитесь, пока Chameleon найдётся автоматически. При необходимости нажмите **«Начать поиск»** и выберите устройство вручную.
2. Перейдите на вкладку **«Метка»** и выберите **QIDI**, **OpenSpool** или **Snapmaker U1**.
3. Приложите метку к Chameleon и нажмите **«Прочитать метку»** или заполните данные и нажмите **«Записать метку»**. Запись проверяется чтением после записи.
4. Чтобы сохранить данные, нажмите **«Сохранить в данные»**. Без этого метка в список не попадёт.
5. Вкладка **«Данные»** содержит сохранённые метки. Оттуда можно записать метку повторно, переименовать или удалить запись, экспортировать `.bin`.
6. Для импорта `.bin` нажмите **«Импорт .bin»** во вкладке «Данные». Поддерживаются QIDI (1024 байта), NTAG215 (540 байт) и NTAG216 (924 байта).
7. Для U1 откройте **«Настройки» → Snapmaker U1**, укажите host/port, сохраните и нажмите **«Проверить»**. Отправка доступна из формы U1 и из сохранённой U1-записи.

Без Chameleon остаются доступны сохранение, работа со списком меток, импорт/экспорт `.bin` и отправка на U1. Кнопки чтения и записи метки при этом отключены.

## Форматы

### QIDI

- Метка: MIFARE Classic 1K.
- Данные: блок 4, 16 байт.
- Байты: `[material_id, color_id, manufacturer_id, 0, ... 0]`.
- Дамп `.bin`: 1024 байта, данные находятся по смещению `4 × 16 = 64`.
- UID и служебные блоки при экспорте заполняются автоматически, если их нет в исходной метке.

### OpenSpool

- Метки: NTAG215 (135 страниц, 504 байта) или NTAG216 (231 страница, 888 байт).
- CC: `E1 10 3E 00` для NTAG215, `E1 10 6D 00` для NTAG216.
- NDEF-запись с MIME `application/json`.
- JSON содержит `protocol: "openspool"`, `version: "1.0"`, тип материала и цвет; для U1 добавляются расширенные поля.
- Пользовательские данные: страницы 4–129 (NTAG215) или 4–225 (NTAG216).
- Дамп `.bin`: 540 байт (NTAG215) или 924 байта (NTAG216).
- NTAG213 не поддерживается.

### QIDI CFG

Импортируется текстовый конфигурационный файл с секциями `[filaN]` и полями вроде `filament`, `type`, `min_temp`, `max_temp`, `box_min_temp`, `box_max_temp`. Импортированный список заменяет встроенный до сброса CFG в настройках.

## Настройки

- **Язык / Language** — русский или английский.
- **Автоматическое сканирование** — повторять поиск Chameleon при запуске и после потери связи.
- **Автоматически подключаться к последнему** — подключаться к ранее использованному устройству, если оно найдено.
- **QIDI CFG** — импорт `.cfg` и сброс к встроенным спискам.
- **Snapmaker U1** — host, port и проверка ToolHead.

Ручное редактирование встроенных списков материалов и производителей пока не реализовано; для QIDI используется импорт CFG.

## Технологии

- Flutter / Dart, Material 3.
- `provider` — состояние приложения.
- `flutter_blue_plus` — BLE.
- `shared_preferences` — настройки и выбранные параметры.
- `path_provider` — локальное хранение записей.
- `file_picker` — импорт и экспорт файлов.
- `http` — запросы к Snapmaker U1.
- `permission_handler` — разрешения Android.

Данные хранятся локально на телефоне. Сеть используется только для обращения к Snapmaker U1.

## Структура проекта

```text
lib/
  core/
    ble/                 подключение к Chameleon, автопоиск
    chameleon/           BLE-транспорт и протокол Chameleon
  data/
    qidi/                модели, списки, CFG и .bin QIDI
    openspool/           модели, NDEF и .bin OpenSpool
    records/             сохранённые метки
    snapmaker/           настройки и модели U1
  services/              чтение/запись меток, HTTP-клиент U1
  ui/                    экраны: подключение, метка, данные, настройки
  l10n/                  русско-английские переводы
```

## Сборка

Проект собирается стандартными средствами Flutter. Release APK подписывается отдельным ключом; параметры подписи и сам ключ хранятся локально и не входят в репозиторий. Готовые universal и per-ABI сборки складываются в `relase/`.

## Статус и ограничения

- Чтение и запись QIDI проверены на реальном Chameleon и метке MIFARE Classic 1K.
- OpenSpool на NTAG215/216 и интеграция с Snapmaker U1 ещё не проверены на реальном оборудовании.
- Поддерживается только Android; iOS-версии нет.
- Нет USB OTG, управления слотами и эмуляцией, DFU/прошивки, журналов и калибровки.
- Snapmaker U1 использует HTTP без авторизации; телефон и принтер должны быть в одной сети.
- Приложение не является официальным продуктом QIDI, Snapmaker или OpenSpool.
